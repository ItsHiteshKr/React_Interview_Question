# React Interview Questions

This project contains small React components and interview-style challenges
built with React, Vite, and Tailwind CSS.

## Getting started

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

Run the linter:

```bash
npm run lint
```

## Tech stack

- React
- Vite
- Tailwind CSS
- React Router



## Challenges

### Easy

- **Counter** - Increment and decrement a displayed value.
- **Image Gallery** - Browse a collection of images.
- **Accordion** - Expand and collapse accordion content.
- **Simple Accordion** - A basic single-section accordion.
- **Guess The Number** - Guess a number between 1 and 100, track attempts,
  receive higher/lower feedback, and reset the game.
- **Star Rating** - Select a rating with interactive stars.
- **Telephone Formatter** - Format a phone number as it is entered.
- **String Transformers** - Transform text into different string formats.
- **Steppers** - Navigate through a multi-step flow.
- **Tic Tac Toe** - Play X/O, detect wins and draws, and track scores.

### Medium

- **Calculator** - Calculator component (work in progress).
- **Traffic Lights** - Cycle through traffic light states using configured
  durations.
- **Toast Popup** - Show a dismissible toast with configurable position, type,
  and duration.
- **Modal Popup** - Open a modal with backdrop and Escape-key close options.
- **Password Strength** - Check password criteria and show a strength meter.
- **Grid Lights** - Select grid cells and clear them in reverse selection order.
- **Column Table** - Generate a numbered table with alternating column order.
- **Todo List** - Add, complete, edit, and delete todo items.
- **Stopwatch** - Start, pause, and reset an elapsed-time display.
- **Quiz App** - Answer questions, track correct-answer score, and view results.
